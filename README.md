These files make up the raw data and data analysis performed in the Battery Energy Storage System (BESS) project done by group D03. 
A general summary of the files are given below: 

SmartHomeSeptember.xlsx - The raw data file from the SmartHome study performed in September 2016 in Massachusetts. This file contains the energy consumption and generation data in kWh of a single family home.

ControlCalcs.ipynb - This is the Python code for the solar panel/battery sensitivity analysis that is performed to determine the system requirements to meet the energy demand of the household. 

ProjOpt.ipynb - Includes Budget Optimization model and example trial. Breakeven analysis then completed by running over 3 budgets and 3 time spans (note this takes over and hour to run)
